# Object-Oriented Programming Basics

Each numbered Python file introduces one OOP concept with a small example and
student notes in the comments. Run a file from the project folder, for example:

```powershell
python .\oops_basics\01_classes_and_objects.py
```

## Topics

1. `01_classes_and_objects.py` — classes, objects, attributes, and methods
2. `02_constructors_attributes_and_methods.py` — `__init__`, instance data, and methods
3. `03_encapsulation.py` — keeping data and validation behavior together
4. `04_inheritance.py` — parent and child classes, including `super()`
5. `05_polymorphism.py` — a shared operation with different object behavior
6. `06_abstraction.py` — abstract base classes and required methods
7. `07_composition.py` — building an object from other objects
8. `08_class_and_static_methods.py` — class attributes, class methods, and static methods
